# CLI integration test plan

[한국어](02.%20Plans.ko.md)

The table rows are exercised in order by `Program.Integration` in the [runner source](../../../Program.cs). See the [state table](01.%20Tables.md).

1. Prepare an isolated `ESOT_HOME` and folders A and B. Check that a mismatching file survives a refused registration and that a matching directory can be registered.
2. Write distinguishable contents x1 through x4 to the Korean filename `토끼.psd`. Compare exit codes, conflicting paths, status before and after, file contents, the source receipt and stored snapshots.
3. Add C, verify restore and three-worktree sync, then check that pushing a deletion into a dirty C preserves its edit.
4. Reduce the retention budget to zero and verify pruning and a failed restore. Construct a pending journal and an external edit to check refusal, recovery and a repeated recovery.

The runner calls `Cli.Main` in the same process and captures stdout, stderr and return values. It creates real files and Git history. Each step uses the worktree state established by the preceding step.
