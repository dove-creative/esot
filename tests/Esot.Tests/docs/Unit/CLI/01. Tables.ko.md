# CLI 통합 상태표

[English](01.%20Tables.md)

표의 각 행은 하나의 임시 워크스페이스가 거치는 단계이다. 종료 코드 0은 성공, 1은 작업 오류, 2는 충돌 또는 빨리 감기 거부이다.

| 상태 | 명령 | 기대 결과 |
| --- | --- | --- |
| 등록할 폴더에 같은 경로의 다른 내용이 있음 | `worktree add` | 1. 기존 파일 보존, 워크트리 등록 안 됨 |
| 기존 파일이 원본 커밋과 일치함 | `worktree add` | 0. 등록 성공, 제외된 `.meta`는 복사되지 않음 |
| B만 x2로 변경, A는 x1 | `commit`, `merge B` | A는 x2를 받음. A의 x1은 남고, 한도가 0인 B의 x1은 정리됨 |
| A와 B가 x2에서 각각 x3·x4로 변경 | `push`, `merge`, `merge --theirs` | 첫 두 명령은 2. 파일과 브랜치 유지. 경로를 선택한 병합은 x4 반영 |
| 다른 워크트리에 과거 사본이 있음 | `restore` | x1 복원. 이어서 작업 변경을 덮는 복원은 1 |
| A·B·C가 다른 경로를 커밋함 | `sync A B C` | 세 폴더에 세 파일의 내용이 모두 일치 |
| A에서 파일 삭제, C에는 미커밋 편집 | `push C` | 1. 편집 보존. C가 깨끗해진 뒤 푸시하면 삭제 반영 |
| 한도를 0으로 낮춤 | `gc`, `restore` | 현재 사본은 보존. 마지막 x1 사본이 사라진 뒤 복원은 1 |
| 대기 중인 저널의 경로에 외부 편집이 있음 | `recover`, `commit` | 1. 편집과 저널 보존. 예상 값 복구 후 `recover` 두 번 모두 0 |
| 등록된 워크트리 안의 경로 | `worktree add` | 1. 중첩 등록 거부 |
