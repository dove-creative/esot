# 세 방향 병합 상태표

[English](01.%20Tables.md)

모델의 상태는 한 파일 경로의 공통 조상, 대상(ours), 보낸 쪽(theirs)의 값이다. 각 값은 `a`, `b`, 또는 파일 부재를 뜻하는 `null`이다.

| 입력 상태 | 병합 판정 시 기대 결과 |
| --- | --- |
| 양쪽 값이 같다 | 같은 값을 선택한다. 양쪽이 삭제하면 결과도 삭제이다. |
| 대상만 공통 조상과 다르다 | 대상 값을 선택한다. |
| 보낸 쪽만 공통 조상과 다르다 | 보낸 쪽 값을 선택한다. |
| 양쪽이 공통 조상과 다르고 서로도 다르다 | 충돌을 반환한다. 삭제와 수정도 포함한다. |

모든 상태에서 `EditLocal`과 `EditIncoming`은 해당 쪽 값을 변경하고, `DeleteLocal`과 `DeleteIncoming`은 해당 쪽 값을 `null`로 둔다. `Agree`는 세 값을 현재 대상 값으로 맞춘다. 모든 행동 뒤에 위 표의 병합 판정을 검증한다.
