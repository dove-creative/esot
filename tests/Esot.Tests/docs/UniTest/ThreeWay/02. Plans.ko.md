# UniTest 병합 모델 계획

[English](02.%20Plans.md)

[실행 코드](../../../Program.cs)의 `MergeProject.CreateCompactLabs`가 [상태표](01.%20Tables.ko.md)의 다섯 가지 행동을 제공한다. 각 행동의 단언은 공통 조상과 다른 값을 중복 없이 모아 기대 결과를 계산하고, `ThreeWay.TryChoose`의 성공 여부와 선택값을 대조한다.

`Program.Main`은 새 프로젝트 인스턴스에서 시드 0, 1, 2로 각각 깊이 100의 연속 실행을 수행한다. 각 실행의 최대 깊이가 정확히 100이고 보고된 노드에 실패가 없어야 통과한다. 파일 반영과 브랜치 이동은 [CLI 통합 테스트](../../Unit/CLI/02.%20Plans.ko.md)에서 검증한다.
