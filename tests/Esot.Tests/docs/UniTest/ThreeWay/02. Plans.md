# UniTest merge model plan

[한국어](02.%20Plans.ko.md)

In the [runner source](../../../Program.cs), `MergeProject.CreateCompactLabs` supplies the five actions in the [state table](01.%20Tables.md). After each action, the assertion collects the distinct values that differ from the ancestor, derives the expected outcome, and compares it with the success flag and value from `ThreeWay.TryChoose`.

`Program.Main` starts a new project instance for each of seeds 0, 1 and 2 and requests a continuous run to depth 100. Each run must report a maximum depth of exactly 100 and no failed nodes. File updates and branch movement are covered by the [CLI integration test](../../Unit/CLI/02.%20Plans.md).
