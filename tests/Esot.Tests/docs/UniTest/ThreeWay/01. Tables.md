# Three-way merge state table

[한국어](01.%20Tables.ko.md)

The model state contains three values for one path, its common ancestor, destination (ours) and incoming version (theirs). Each value is `a`, `b` or `null` for an absent file.

| Input state | Expected merge decision |
| --- | --- |
| Both sides agree | Choose their shared value. Two deletions produce a deletion. |
| Only the destination differs from the ancestor | Choose the destination value. |
| Only the incoming side differs from the ancestor | Choose the incoming value. |
| Both differ from the ancestor and from each other | Report a conflict, including a deletion competing with an edit. |

In every state, `EditLocal` and `EditIncoming` change their respective values, and `DeleteLocal` and `DeleteIncoming` set them to `null`. `Agree` sets all three values to the current destination value. The model checks the table's merge decision after every action.
