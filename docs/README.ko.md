# ESOT 개요

[English](README.md)

ESOT(Equal Sources of Truth)는 한 컴퓨터의 여러 워크트리에서 같은 리소스 묶음을 독립적으로 편집하고, 선택한 변경을 다른 워크트리에 반영하는 CLI이다. 각 워크트리의 이름, 현재 커밋, 과거 원본 보관 한도는 서로 독립적이다.

## 토끼 PSD의 두 번의 병합

아래에서 `x1`부터 `x4`까지는 같은 경로에 저장된 PSD 내용의 버전이다.

| 작업 | A의 토끼.psd | B의 토끼.psd | 결과 |
| --- | --- | --- | --- |
| A를 초기화한 뒤 B 워크트리를 추가한다 | x1 | x1 | 두 워크트리가 같은 커밋에서 시작한다. |
| B에서 귀를 추가하고 커밋한다 | x1 | x2 | B의 현재 커밋만 전진한다. |
| A에서 `merge B`를 실행한다 | x2 | x2 | B에 보낸 커밋, A에 받은 병합 커밋이 남는다. |
| A에서 꼬리를 지우고 B에서 손을 추가해 각각 커밋한다 | x3 | x4 | 양쪽 변경의 공통 기준은 x2이다. |
| A에서 다시 `merge B`를 실행한다 | x3 | x4 | 같은 경로가 다르게 바뀌어 종료 코드 2와 경로가 출력된다. 파일과 브랜치 끝은 유지된다. |

충돌 경로에서 A의 내용을 선택할 때는 `--ours`, B의 내용을 선택할 때는 `--theirs`를 지정한다. 어느 쪽을 선택해도 PSD 레이어 편집은 작업자가 사용하는 편집기에서 수행한다.

## 반영 방향

| 명령 | 반영 범위 |
| --- | --- |
| B에서 `push A` | A의 현재 커밋이 B의 이력에 있으면 A를 B의 커밋까지 전진시킨다. |
| A에서 `merge B` | B의 커밋과 A의 커밋을 공통 조상과 비교해 A에 병합한다. 이미 반영된 B를 다시 병합하면 추가 커밋을 만들지 않는다. |
| `sync A B C` | 지정한 워크트리의 커밋을 합쳐 모든 참여 워크트리를 같은 커밋으로 맞춘다. |

설치와 실행 예시는 [한국어 사용법](../README.ko.md), 이력·실제 파일·복구 기록의 관계는 [저장 구조와 복구](Architecture.ko.md), 검증 범위와 실행 기록은 [테스트 안내](../tests/README.ko.md)에 있다.
